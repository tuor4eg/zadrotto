# Выпуск очков за квизы

Очки вычисляются по результатам: `outcome = 'correct'` даёт `attempts_remaining`,
остальные результаты дают 0. Новая формула сразу включает прошлые квизы;
обновление строк участников и отдельное доначисление баланса не нужны.

1. Остановить старые экземпляры приложения и workers перед миграцией,
   удаляющей `is_winner`. Они несовместимы с новой схемой.
2. Применить миграции через обновлённый контейнер `migrate`:
   `docker compose --profile migrate run --rm migrate`.
   Миграция `0106_quiz_achievements_backfill` автоматически создаёт задание
   `achievements.backfill` для включённых ачивок механики `quiz.win.count`.
   Если таких ачивок нет, задание не создаётся. Повторное применение обычной
   команды миграций не создаёт второе задание: миграция учитывается в журнале.
3. Запустить обновлённые контейнеры приложения, scheduler и worker.
   Worker обрабатывает авторов пакетами по 100 и создаёт продолжения backfill.
   Уже выданные уровни сохраняются; повторная обработка не дублирует награды.
4. Проверить завершение задания и его продолжений в журнале jobs, затем сравнить
   сумму очков нескольких авторов с остатками попыток их правильных ответов.

При лимите 3 ответы с первой, второй и третьей попыток дают 3, 2 и 1 очко.
Таблица лидеров включает всех авторов с положительной суммой; при равенстве
сортируется по сумме времени правильных ответов от начала квизов, имени и ID.
