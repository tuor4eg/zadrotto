# Changelog

This project is still in pre-release development. The entries below group the existing commit history into product milestones rather than individual changes.

## [0.8.0.0008] - 2026-07-30

Added login-based author accounts, registration and email administration. Expanded external data support with AniList and FantLab, title aliases, media-type permissions, avatars, and a hierarchical series workflow.

## [0.7.0.0007] - 2026-07-19

Added imported media metadata to records and archive previews. Continued the admin redesign, introduced anime and book presentation, and improved provider search and catalog polish.

## [0.6.0.0006] - 2026-07-01

Introduced series relationships for records, including multiple series and dedicated archive presentation. Added more carrier skins and refined carrier selection by release year.

## [0.5.0.0005] - 2026-06-19

Added configurable content providers, administrative tools, Redis-backed infrastructure, and cover thumbnails. Expanded carrier-specific presentation and completed broad mobile adaptations for the archive and admin interface.

## [0.4.0.0004] - 2026-06-07

Introduced configurable media types and carriers, cover discovery, and the first console-inspired carrier skins. Reworked the author dashboard and added consistent administrative toast notifications.

## [0.3.0.0003] - 2026-05-31

Expanded the author system with access profiles, experience dates, reviews, and moderation flows. Reworked author-facing pages and stabilized the related admin workflows.

## [0.2.0.0002] - 2026-05-18

Started the archive visual redesign and iterated on navigation, tabs, responsive behavior, and catalog presentation. Added the first real imported game collection and completed early production hardening.

## [0.1.0.0001] - 2026-05-06

Created the initial Next.js and PostgreSQL application with the core archive entities and project instructions. Added the first series model and early author approval flow.
