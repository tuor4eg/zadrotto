# Архив миграций до baseline

`pre-baseline/` сохраняет полную прежнюю цепочку 0000–0161 и исходный каталог `meta/`, включая изменения, ещё не закоммиченные на момент перехода. Эти файлы используются историческими регрессионными тестами и не исполняются штатным migrator.

Для новой пустой БД используется только `drizzle/0000_baseline.sql`. Следующие миграции добавляются в `drizzle/`, а не в архив. Порядок и содержимое старых миграций не меняются.

Ограничения восстановления существующей БД описаны в [документации baseline](../docs/architecture/DATABASE_BASELINE.md).
